## Quick Commands by License Type

### MIT License (Default - Most Projects)
```bash
cp LICENSE [repo]/LICENSE
```

### Apache 2.0 License (Patent Protection)
```bash
cp LICENSE.APACHE [repo]/LICENSE
```

### CC0 License (Documentation)
```bash
cp LICENSE.CC0 [repo]/LICENSE
```
